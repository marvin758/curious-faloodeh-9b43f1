ISL DISTRIBUTORS WEBSITE — REBUILT VERSION
==========================================

This package is ready for direct deployment to Netlify.
The official ISL logo is included at: assets/isl-logo.png

FILES
-----
index.html       Main website page
styles.css       All website styling and mobile layout
script.js        Navigation, product filtering and animations
thank-you.html   Confirmation page for the enquiry form
netlify.toml     Netlify publishing and basic security headers
assets/          ISL logo and favicon

BEFORE PUBLISHING
-----------------
1. Open index.html in a text editor.
2. Search for: Add business email
3. Replace it with the official ISL email address.
4. Search for: Add business number
5. Replace it with the official phone or WhatsApp number.
6. Review product descriptions and add or remove products as required.

CONTACT FORM ON NETLIFY
-----------------------
The form is configured for Netlify Forms.
After the site is deployed:
1. Open the Netlify project dashboard.
2. Open Forms.
3. Confirm that the form named "quote-request" is detected.
4. Add email notifications under form notifications.

DEPLOYMENT
----------
Upload the entire ZIP file using Netlify's manual deployment area.
The index.html file is at the ZIP root, so Netlify will load the website directly.

There is no "under construction" message in this package.
